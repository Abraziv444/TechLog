# `dictionary/books` — учебники разделов

Сюда кладутся сами учебные материалы — то, что сотрудник читает перед тестом.
Имя файла прописано в `dictionary/index.json`, поле `book` у раздела:

```json
"book": { "ru": "books/section-1-ru.html", "en": "books/section-1-en.html" }
```

Какая книга откроется, решает **язык интерфейса в Настройках** (RU / EN).
Если книга одна на оба языка — можно по-старому строкой:
`"book": "books/section-8.html"`. Файла нет — кнопка «Книга» у раздела гаснет.

## Учебник из PDF: как он устроен

`section-N-xx.html` — один самодостаточный файл: все страницы, картинки и
шрифты внутри, ничего снаружи не подгружается. Каждая страница — SVG
612×792 pt (US Letter) из трёх слоёв: векторы (заливки, рамки, схемы,
отточия), картинки (WebP) и текст. Положение каждой строки совпадает с PDF,
текст выделяется, копируется и ищется. Шрифт единый для всех учебников —
**PT Serif** (основной текст) и **PT Sans** (заголовки, подписи), кириллица и
латиница; в файл вшит только набор используемых знаков.

Внутри — свой просмотрщик:

- оглавление (собирается автоматически по колонтитулам страниц), миниатюры
  страниц, поиск по всей книге с подсветкой найденного;
- переход по номеру страницы — понимает книжную нумерацию (титульные листы
  без номера идут отдельно);
- масштаб: кнопки, `Ctrl`+колесо, щипок на телефоне, «по ширине» / «страница
  целиком»;
- два режима: лента страниц и листание по одной (свайп влево-вправо);
- темы обычная / сепия / тёмная, полноэкранный режим;
- клавиатура: `← →` страницы (в режиме листания), `+ −` масштаб, `0` — 100 %,
  `F` или `/` — поиск, `Home`/`End`;
- книга запоминает последнюю страницу, масштаб и тему на этом устройстве.

Рамка чтения открывается с `allow-scripts` — скрипты внутри учебника
работают (нужно для листалки). Тёмная тема приложения к странице не
применяется: у книги своя.

## Как собрать учебник для следующего раздела

Нужны PDF-файлы раздела (титулы отдельным файлом — `… page ТИТУЛЫ.pdf` или
`… page i - iii.pdf`, остальные — `… page 21 - 36.pdf` и т. п.; порядок и
номера страниц берутся из имён, римские тоже понимаются).

```bash
cd dictionary/books/tools
pip install pymupdf pillow fonttools brotli --break-system-packages   # один раз

python3 pdf2book.py --src /путь/к/RU --out ../section-2-ru.html --lang ru \
        --section 2 --title "Восстановление после пожара и копоти" --color "#FF4B4B"
python3 pdf2book.py --src /путь/к/EN --out ../section-2-en.html --lang en \
        --section 2 --title "Fire and Smoke Restoration Technology" --color "#FF4B4B"
```

Шрифты PT Serif / PT Sans при первом запуске скачаются сами в `tools/fonts/`
(с github.com/google/fonts, лицензия OFL); если сети нет — положите восемь
`.ttf` туда вручную. `--color` — цвет закладки раздела из `index.json`.
Ключи `--ppt` (пикселей на пункт в картинках, по умолчанию 2.5) и
`--quality` (WebP, 72) регулируют размер файла: 170 страниц с 200 фото —
около 8 МБ.

После сборки впишите файлы в `index.json` — и книга появится в приложении
у всех после обновления каталога (без смены версии).

## Другие форматы

| Формат | Как показывается | Замечания |
|---|---|---|
| `.html` | внутри приложения, в своей рамке | лучший вариант: схемы, картинки, таблицы, поиск |
| `.pdf`  | встроенный просмотрщик браузера | на телефоне часто открывается системным просмотрщиком — есть кнопка «Открыть в новой вкладке» |
| `.md`   | показывается как текст | без оформления, на крайний случай |

Простая html-страница (как `section-8.html`) — обычный файл со стилями
внутри `<style>`; картинки `data:`-строкой или файлом рядом. Всё, что открыли
хоть раз, кладётся в кэш приложения и потом читается без интернета.

## Время чтения

Приложение само засекает, сколько человек читал материал: таймер идёт,
пока страница открыта и телефон не в кармане (сворачивание останавливает
счёт). Результат попадает в статистику администратора вместе с временем
тестов — ничего размечать в самом файле не нужно.
